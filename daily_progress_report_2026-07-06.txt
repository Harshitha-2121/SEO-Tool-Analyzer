SUMMARY
-------
Today's session focused on creating a single, persistent, global sidebar component
for the multi-page Vite HTML application. The legacy design duplicated the sidebar
markup and CSS in every HTML page (evidenced by the previous _patch_sidebars.py
maintenance script). A new shared sidebar.js component was created to centralize
all navigation UI, behavior, and theming.

DELIVERABLES COMPLETED TODAY
----------------------------

1. GLOBAL SIDEBAR COMPONENT
   File: seo-audit-platform/sidebar.js
   - Single source of truth for all sidebar HTML, CSS, and behavior.
   - Injects a fixed <aside id="sidebar"> once per page via vanilla JS.
   - Injects shared CSS variables and layout rules once per page.
   - Detects current page filename and marks the correct nav item as active.
   - Supports desktop fixed width (280px), collapsed width (68px), and mobile
     off-canvas drawer modes from the same component.
   - Collapse/expand state is persisted in localStorage.
   - Hover-expand behavior on collapsed desktop state.
   - Mobile hamburger toggle and overlay close behavior.

2. NAVIGATION STRUCTURE
   - Dashboard
   - Crawl & Audit: SEO Scanner, SEO Analyzer, Page Counter
   - Intelligence: Competitor Engine, Content Gap, Intent Analyzer, Internal Links
   - Technical: Technical SEO, AutoFix, Performance, Security & A11y
   - AI Tools: AI Copilot, AI Roadmap, Digital Twin
   - Analytics: Reports, History

3. LAYOUT MODELS SUPPORTED
   - Type A: <div class="app"> container with sidebar + main as flex children.
   - Type B: <body> as flex container with sidebar + main margin-left offset.
   - Main content offset is applied via CSS so the sidebar does not rebuild,
     resize, or animate on navigation; only the active nav item changes.

4. DESIGN / THEME SYSTEM
   - CSS custom properties for colors, spacing, transitions, and widths.
   - Dark premium theme with purple accent (#6c5ce7), glassmorphic touches,
     consistent typography, hover/active states, and active indicator stripe.

5. RESPONSIVE BEHAVIOR
   - Desktop (>1024px): fixed 280px sidebar, optional collapse.
   - Tablet (768px-1024px): auto-collapsed to 68px, hover expands.
   - Mobile (<768px): hidden off-canvas drawer, hamburger toggle.

6. USER FOOTER
   - Reads user_email from localStorage for personalized initials/name.
   - Sign Out button clears login state and redirects to login.html.

7. CLEANUP
   - The component removes stale sidebar scripts/styles by ID when it initializes:
     sidebar-active-highlight-script, sidebar-active-script, sidebar-redesign-overrides.

       headings, internal links)
     * AI Outranking Battle Plan narrative (returned by backend / AI)
   - Error handling with timeout detection and troubleshooting steps.

FEATURE SPOTLIGHT: AI SEO COPILOT (NEW)
----------------------------------------
Files: seo-audit-platform/ai-copilot.html, ask-ai.js
   - Full-page chat interface with persistent history panel.
   - Powered by a local Ollama LLM via /api/ask-ai endpoint.
   - Context modes: General SEO, Technical, Content, Competitor, Local SEO.
   - Context URL input pre-filled from current_scanned_domain in localStorage.
   - Quick-start cards for Core Web Vitals, Internal Linking, Schema Markup,
     and Keyword Gap Analysis.
   - Chat history saved to localStorage (max 20 conversations).
   - Floating "Ask AI" drawer (ask-ai.js) available across pages, which:
     * Injects a floating button on supported pages
     * Opens a slide-in drawer from the right
     * Sends user questions to /api/ask-ai with real_scan_data crawl context
     * Falls back to a built-in rule-based conversational engine if the AI
       endpoint is unreachable
   - Rule-based engine covers greetings, LCP/CLS/TTFB definitions, sitemap
     explanation, robots.txt, H1/heading checks, image alt tags, general SEO
     score/status, and a default prompt to run a live audit.
